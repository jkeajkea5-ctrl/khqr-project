1. Project Summary

TEAM10 Clothing Store is a Laravel-based web application that combines a public shopping interface, user sign in and registration, session cart management, KHQR payment processing, invoice generation, and a role-based admin workspace for managing products, categories, slides, orders, and staff.

Platform and package stack

Laravel 12 PHP 8.2 Bootstrap 5.3 Vite 7 KHQR Gateway Simple QRCode Bootstrap Icons

Main feature groups

  • Storefront browsing with category filters and product cards.
  • User registration and sign-in with phone or email support.
  • Product detail pages with size and color selection.
  • Cart, checkout, KHQR payment verification, and invoice output.
  • Admin dashboard analytics with revenue, units sold, and payment status charts.
  • Role-based staff access for admin, stock controller, and employee accounts.

3. Project Process

The application has two major tracks: the customer purchase journey and the admin management workflow. The diagram below gives a high-level map of the full system process.

Flow map covering shopping, KHQR payment confirmation, and admin-side operations.

Customer journey

  1. User opens the home page and browses products by category or search.
  2. User registers or signs in when account-based checkout is needed.
  3. User reviews product detail, selects size and color, then adds the item to cart.
  4. User reviews the cart and proceeds to the KHQR checkout screen.
  5. The system generates a QR code, stores a pending order, and waits for Bakong verification.
  6. After confirmation, the order becomes paid and the invoice page is displayed.

Admin workflow

  1. Admin signs in through the dedicated back-office login page.
  2. The dashboard shows revenue, trends, paid orders, top products, and order mix.
  3. Catalog pages manage products, categories, colors, sizes, and slideshow assets.
  4. Operational pages track order history, paid payments, and staff/user access.
  5. Role checks decide which staff can create, edit, or delete each resource.
