3. ដំណើរការគម្រោង

ប្រព័ន្ធនេះមានលំហូរសំខាន់ពីរ គឺដំណើរទិញទំនិញរបស់អតិថិជន និងលំហូរការងាររបស់ Admin។ រូបខាងក្រោមបង្ហាញដំណើរការសរុបទាំងមូល។

ផែនទីសង្ខេបនៃការទិញទំនិញ ការទូទាត់ KHQR និងការគ្រប់គ្រងផ្នែក Admin។

លំហូរអតិថិជន

  1. អតិថិជនចូលមើលទំព័រមេ ហើយស្វែងរកផលិតផលតាម category ឬ search។
  2. នៅពេលត្រូវ Checkout អតិថិជនអាចចុះឈ្មោះ ឬចូលគណនី។
  3. អតិថិជនមើលទំព័រលម្អិត ជ្រើសទំហំ និងពណ៌ រួចបន្ថែមចូលកន្រ្តក។
  4. បន្ទាប់មកពិនិត្យកន្រ្តក ហើយបន្តទៅអេក្រង់ទូទាត់ KHQR។
  5. ប្រព័ន្ធបង្កើត QR code រក្សាទុក pending order ហើយរង់ចាំការផ្ទៀងផ្ទាត់ពី Bakong។
  6. បន្ទាប់ពីបង់ប្រាក់ជោគជ័យ order នឹងក្លាយជា paid ហើយបង្ហាញវិក្កយបត្រ។

លំហូរ Admin

  1. Admin ចូលប្រព័ន្ធតាមទំព័រចូល back-office ដែលបានបំបែកចេញ។
  2. Dashboard បង្ហាញចំណូល និន្នាការ paid orders top products និង order mix។
  3. ផ្នែក catalog គ្រប់គ្រង products, categories, colors, sizes និង slides។
  4. ផ្នែកប្រតិបត្តិការ តាមដាន order history, paid payments និងការចូលប្រើរបស់បុគ្គលិក។
  5. Role checks កំណត់ថានរណាអាច create, edit ឬ delete resource នីមួយៗ។

4. រូបភាពផ្នែកអតិថិជន

រូបភាពខាងក្រោមបង្ហាញលំហូរផ្នែកអតិថិជនដោយប្រើ screenshot ថ្មីៗពី docs/assets។ រូប T-shirt ថ្មីត្រូវបានបង្ហាញទាំងនៅលើ storefront និង admin product list។

ទំព័រមេ

បង្ហាញ category filters, product cards និងរូប T-shirt ថ្មីនៅក្នុង storefront listing។

ទំព័រចុះឈ្មោះ

Form សម្រាប់បង្កើតគណនីថ្មី ដោយមានលេខទូរស័ព្ទ អ៊ីមែលជាជម្រើស និងពាក្យសម្ងាត់។

ទំព័រចូលគណនី

អនុញ្ញាតឲ្យអ្នកប្រើចូលតាមលេខទូរស័ព្ទ ឬអ៊ីមែល។

ទំព័រលម្អិតផលិតផល

បង្ហាញរូបផលិតផល ការជ្រើសទំហំ ពណ៌ និងប៊ូតុងទិញ។

កន្រ្តកទំនិញ

អតិថិជនអាចពិនិត្យទំនិញ កែចំនួន លុប ឬបន្តទៅការទូទាត់។

ទំព័រទូទាត់ KHQR

បង្ហាញ QR, reference number, total amount និងស្ថានភាពផ្ទៀងផ្ទាត់ការទូទាត់។

វិក្កយបត្របន្ទាប់ពីបង់ប្រាក់

បង្ហាញព័ត៌មានអតិថិជន បញ្ជីទំនិញ និងស្ថានភាព PAID បន្ទាប់ពីបង់ប្រាក់ជោគជ័យ។

Admin login
